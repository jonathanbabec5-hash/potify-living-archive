# The Living Archive
## Whitepaper · public developer edition

**November 25, 2026 · Application source**

### Goal and audience

Make the full Seed → New Cycle journey explorable as an illustrated archive. The immediate audience is readers learning the craft and archival designers.

### Design and implementation

Static stage records and illustrations drive the client. Progression gives every grow log a shared vocabulary across twelve stages. Use the twelve canon stage names consistently across illustration, navigation and grow notes. The current version associates an authored observation with each stage.

### What a contributor can establish

The public entry page returned HTTP 200 and rendered local content in Chromium at a 390 × 844 viewport. An illustration identifies a stage. It is a separate asset from a grower's dated observation and cannot substantiate a grow outcome.

### Evidence and outstanding work

Display assets are a dated version. An illustration update belongs in a later reviewed revision. The next acceptance case is concrete. Reach all twelve canon stages on mobile and confirm their ordering and descriptions.

### Place in POTIFY

Test demand for a twelve-stage print set using an opt-in sample, then count fulfilled print orders. The marketing plan gives the test window and the evidence for a commercial outcome.
